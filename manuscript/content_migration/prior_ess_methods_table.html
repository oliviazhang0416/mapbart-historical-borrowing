Normal–normal comparison

The following derivations isolate the reference information used by each method under normal sampling models. Each subsection starts from that method’s reference construction and ends with its reference information quantity.

Neuenschwander et al. (2010): complete-pooling calibration

Neuenschwander’s normal random-effects model starts from (H) historical trial estimates,

Yh∣θh∼N(θh,σh2),h=1,…,H, Y_h\mid\theta_h\sim N(\theta_h,\sigma_h^2), \qquad h=1,\ldots,H,

with exchangeable historical and new-trial parameters

θ1,…,θH,θ⋆∣μ,τ2∼iidN(μ,τ2). \theta_1,\ldots,\theta_H,\theta_\star \mid\mu,\tau^2 \overset{\mathrm{iid}}{\sim} N(\mu,\tau^2).

For fixed (), first integrate out (_h):

Yh∣μ,τ∼N(μ,σh2+τ2). Y_h\mid\mu,\tau \sim N(\mu,\sigma_h^2+\tau^2).

Under the paper’s locally uniform prior for (), define

wh(τ)≔1σh2+τ2,Wτ≔∑h=1Hwh(τ),μ̂τ≔∑h=1Hwh(τ)YhWτ. w_h(\tau)\coloneqq\frac1{\sigma_h^2+\tau^2}, \qquad W_\tau\coloneqq\sum_{h=1}^H w_h(\tau), \qquad \widehat\mu_\tau \coloneqq\frac{\sum_{h=1}^H w_h(\tau)Y_h}{W_\tau}.

Normal conjugacy gives the posterior distribution of the common location:

μ∣DH,τ∼N(μ̂τ,1Wτ). \mu\mid D_H,\tau \sim N\!\left(\widehat\mu_\tau,\frac1{W_\tau}\right).

Next use (_,N(,^2)) and integrate over the posterior of (). The meta-analytic predictive distribution is

θ⋆∣DH,τ∼N(μ̂τ,Vτ), \theta_\star\mid D_H,\tau \sim N\!\left(\widehat\mu_\tau,V_\tau\right),

where

Vτ≔1Wτ+τ2=1∑h=1H1σh2+τ2+τ2. V_\tau \coloneqq\frac1{W_\tau}+\tau^2 =\frac{1}{\displaystyle\sum_{h=1}^H \frac1{\sigma_h^2+\tau^2}} +\tau^2.

If the variance of historical trial estimate (h) is (_h2=2/n_h), then

wh(τ)=1σ2/nh+τ2=nhσ2+nhτ2, w_h(\tau) =\frac{1}{\sigma^2/n_h+\tau^2} =\frac{n_h}{\sigma^2+n_h\tau^2},

and, for possibly unequal trial sizes,

Vτ=1∑h=1Hnhσ2+nhτ2+τ2. V_\tau =\frac{1}{\displaystyle\sum_{h=1}^H \frac{n_h}{\sigma^2+n_h\tau^2}} +\tau^2.

If all (H) historical trials have size (n_h=n), define the total historical sample size as (N_HHn). Then

Vτ=σ2+nτ2Hn+τ2=σ2NH+τ2(1+1H). V_\tau =\frac{\sigma^2+n\tau^2}{Hn}+\tau^2 =\frac{\sigma^2}{N_H} +\tau^2\left(1+\frac1H\right).

Complete pooling is the special case (). Hence

V0≔Var(θ⋆∣DH,τ=0)=1∑h=1H1σh2,ℐ0≔1V0=∑h=1H1σh2. V_0 \coloneqq\operatorname{Var}(\theta_\star\mid D_H,\tau=0) =\frac{1}{\displaystyle\sum_{h=1}^H\frac1{\sigma_h^2}}, \qquad \mathcal I_0\coloneqq\frac1{V_0} =\sum_{h=1}^H\frac1{\sigma_h^2}.

When (h2=2/n_h), define (N_H{h=1}^Hn_h). Then

V0=σ2NH,ℐ0=NHσ2. V_0=\frac{\sigma^2}{N_H}, \qquad \mathcal I_0=\frac{N_H}{\sigma^2}.

The complete-pooling prior is assigned its historical count (N_H). Therefore, its implied information per reference patient is

ℐref,1≔ℐ0NH=1NHV0=1σ2. \boxed{ \mathcal I_{\mathrm{ref},1} \coloneqq\frac{\mathcal I_0}{N_H} =\frac1{N_HV_0} =\frac1{\sigma^2}. }

Morita–Thall–Müller (2008): reference-posterior curvature

Let the normal reference likelihood and the same-mean ()-information prior be

Yj∣θ⋆∼iidN(θ⋆,σ2),j=1,…,m,πϵ≔N(μ0,Vϵ). Y_j\mid\theta_\star\overset{\mathrm{iid}}{\sim}N(\theta_\star,\sigma^2), \qquad j=1,\ldots,m, \qquad \pi_\epsilon\coloneqq N(\mu_0,V_\epsilon).

The resulting reference posterior is normal. Its variance is

Vϵ,m≔(1Vϵ+mσ2)−1. V_{\epsilon,m} \coloneqq\left(\frac1{V_\epsilon}+\frac{m}{\sigma^2}\right)^{-1}.

For a normal posterior, log-posterior curvature equals inverse variance. Therefore, Morita’s reference information quantity is

ℐref(m)≔1Vϵ,m=1Vϵ+mσ2. \boxed{ \mathcal I_{\mathrm{ref}}(m) \coloneqq\frac1{V_{\epsilon,m}} =\frac1{V_\epsilon}+\frac{m}{\sigma^2}. }

The posterior variance does not depend on the realized hypothetical observations, so no further averaging over their values is needed in this normal case.

ELIR: one-observation Fisher information

For one observation from the normal reference likelihood,

Y1∣θ⋆∼N(θ⋆,σ2), Y_1\mid\theta_\star\sim N(\theta_\star,\sigma^2),

the expected Fisher information is

ℐref(θ⋆)≔iF(θ⋆)=EY1∣θ⋆[−d2dθ⋆2logf(Y1∣θ⋆)]=1σ2. \boxed{ \mathcal I_{\mathrm{ref}}(\theta_\star) \coloneqq i_F(\theta_\star) =E_{Y_1\mid\theta_\star}\!\left[ -\frac{d^2}{d\theta_\star^2}\log f(Y_1\mid\theta_\star) \right] =\frac1{\sigma^2}. }

It is constant in (_). Consequently, (m) independent reference observations provide (m/^2) information. ELIR uses no reference prior.

Proposed conditional variance-matching definition

The proposed method uses the same one-observation reference source as ELIR:

Y1∣θ⋆∼N(θ⋆,σ2). Y_1\mid\theta_\star\sim N(\theta_\star,\sigma^2).

Thus its reference information quantity is also

ℐref(θ⋆)≔iF(θ⋆)=1σ2, \boxed{ \mathcal I_{\mathrm{ref}}(\theta_\star) \coloneqq i_F(\theta_\star) =\frac1{\sigma^2}, }

and (m) independent reference observations provide

mℐref(θ⋆)=mσ2. m\,\mathcal I_{\mathrm{ref}}(\theta_\star) =\frac{m}{\sigma^2}.

No reference prior is required. In the manuscript specialization, the table’s (_) is (), and the reference variance is (2^2), so (i_F()=1/_2^2).
